## Architecture Summary

Astrology v2 is a **Swiss Ephemeris–backed chart and transit engine**
living primarily in the SEN stream at `/opt/mythos/astrology/`. It
produces two things: **natal charts** (static per-person snapshots stored
Postgres-first with JSON artifacts) and **daily transit reports** (how
the current sky activates a natal chart, with Ollama-powered Iris-voiced
interpretations).

The engine uses `pyswisseph` directly via the **Master Ephemeris
Provider** (`astrology/ephemeris.py`). Kerykeion is retained for SVG
chart rendering only, and is configured to use the same ephemeris path.

All planetary position data flows through `ephemeris.py`. All natal
chart reads flow through `natal_generator.load_natal()`. All transit
computations flow through `transit_pressure.py` + `transit_interpreter.py`.
Interpretations are generated by `transit_interpreter.py` using
`qwen3:30b-a3b` with `num_predict=2048` (see SEN-0015 notes).

Ephemeris files live at `/opt/mythos/astrology/ephe/` (canonical).
The old `/opt/mythos/ephemeris/` path is archived at
`/opt/mythos/archive/ephemeris_pre_astro_v2/`.

## How to use

### Daily transits (Telegram)

```
/transits              — today, Adge, full Ollama interpretations (~60s)
/transits seraphe      — today, Seraphe
/transits brief        — today, Adge, no LLM (instant)
/transits date 2026-04-28  — specific date
```

### Daily transits (CLI)

```bash
daily-transits                    # today, Adge, full
daily-transits seraphe            # today, Seraphe
daily-transits adge 2026-04-28    # specific date
daily-transits brief              # fast, no Ollama
```

### Load a natal chart programmatically

```python
from astrology.natal_generator import load_natal
chart = load_natal('Adge')  # reads from Postgres via socket
planets = chart['chart_objects']
sun_lon = planets['Sun']['longitude']
```

### Compute transits programmatically

```python
from astrology.spiral.transit_pressure import run_daily_pressure
# run_daily_pressure = compute + persist + return (correct entry point)
aspects = run_daily_pressure(chart_id=9)  # Adge

# get_todays_pressure = DB cache read ONLY (use only if already computed today)
from astrology.spiral.transit_pressure import get_todays_pressure
aspects = get_todays_pressure(chart_id=9)
```

## Known issues / debt

1. **Chart 17 wrong birth year** — `Adriaan Harold Denkers` has 1978 (should be 1977). Do not use.

2. **`weekly_report.py` uses Kerykeion directly** — not migrated to `ephemeris.py`. Covered by audit REQUESTS.md entry.

3. **`astrochart_cli_engine.py` monolith** — 1500 LOC with its own constants. Covered by audit.

4. **`transit_pressure.py` narrow orbs** — 3° maximum for all aspects. Intentional for spiral time context.

5. **`integrity.graph` crash loop** — `mythos-obs-graph.service` auto-restarts. Causes `⊘ Graph: integrity.graph not available` in every post-install pipeline. Unrelated to astrology.

6. **Transit interpretations are slow** — qwen3:30b-a3b with num_predict=2048 makes one Ollama call per building/exact aspect. 7 aspects ≈ 60-90 seconds. Use `/transits brief` for instant results.

7. **`astro_events` has no chart_id column** — stores sky events (ingresses, stations, eclipses), not personal transits. Don't query it for transit data.

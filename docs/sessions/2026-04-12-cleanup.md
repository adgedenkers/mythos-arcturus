## Lessons

- The monitor service running as adge internally `sudo bash`ed patches,
  which caused every auto-installed patch to run as root and drop
  root-owned artifacts across `/opt/mythos/` and `/tmp/`. SYS-0066 made
  the monitor passive — it now only notifies, never runs.
- Patches that escalate to root via `sudo bash install.sh` must either
  (a) not touch `/opt/mythos/` git history from root, or (b) chown back
  to adge before exiting. SYS-0068 uses the chown-back pattern.
- Root processes don't have adge's SSH agent, so `git push` from within
  a root-escalated patch will fail silently. Git push should happen
  from the adge-owned patch-install wrapper, not inside apply_patch.py.
- `py_compile` writes `.pyc` files to `__pycache__/` next to the source.
  When the source is in `/tmp/` and `/tmp/__pycache__/` is root-owned
  from a prior root run, later adge-run compiles fail. Fix: use
  `py_compile.compile(src, cfile=<path inside owned tmpdir>)` so
  `__pycache__` resolution is bypassed entirely.
- `shutil.move()` preserves the tempfile's restrictive default perms
  (0600). When the target file needs different perms, call
  `shutil.copystat(target, tmp)` before the move.

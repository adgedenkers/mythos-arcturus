### Documentation for `mx/mx_delta.py`

#### Purpose
The `mx_delta.py` file is responsible for comparing two system snapshots and generating a detailed report of the changes, categorized into additions, changes, regressions, and neutral changes. It also provides functionality to print this report in a human-readable format.

#### Architecture
- **Classes**:
  - `DeltaEntry`: Represents a single change entry with details such as category, key, before and after states, change type, and message.
  - `DeltaReport`: Aggregates multiple `DeltaEntry` objects and provides methods to add entries, generate a summary line, and convert the report to a dictionary.
- **Functions**:
  - `diff_snapshots`: Compares two snapshots and produces a `DeltaReport`.
  - `print_delta_report`: Formats and prints the `DeltaReport` to the terminal.

#### Patterns
- **Data Class Pattern**: `DeltaEntry` and `DeltaReport` are implemented using Python's `dataclass` to simplify the creation and management of immutable objects.
- **Builder Pattern**: `DeltaReport` acts as a builder, accumulating changes and providing methods to summarize and serialize the report.

#### Dependencies
- **Imports**:
  - `dataclasses`: For defining `DeltaEntry` and `DeltaReport` as data classes.
  - `typing`: For type annotations, specifically `Literal` for defining `ChangeType`.

#### Interfaces

  - `diff_snapshots(before: dict, after: dict) -> DeltaReport`: Compares two snapshots and returns a `DeltaReport`.
  - `print_delta_report(report: DeltaReport, pre_label: str = "pre", post_label: str = "post")`: Prints the `DeltaReport` to the terminal with optional labels for pre and post snapshots.

#### Key Logic

### Detailed Breakdown

#### `DeltaEntry` Class
- **Purpose**: Represents a single change entry.
- **Attributes**:
  - `category`: The category of the change (e.g., "services", "git", "postgres").
  - `key`: The specific item that changed.
  - `before`: The state before the change.
  - `after`: The state after the change.
  - `change_type`: The type of change (ADDITION, CHANGE, REGRESSION, NEUTRAL).
  - `message`: A human-readable message describing the change.

#### `DeltaReport` Class
- **Purpose**: Aggregates multiple `DeltaEntry` objects and provides methods to summarize and serialize the report.
- **Attributes**:
  - `entries`: A list of `DeltaEntry` objects.
  - `regressions`: A list of regression messages.
  - `has_regressions`: A boolean indicating if any regressions are present.
- **Methods**:
  - `add(entry: DeltaEntry)`: Adds a `DeltaEntry` to the report and updates the `regressions` and `has_regressions` attributes if the entry is a regression.
  - `summary_line()`: Generates a summary line indicating the number of additions, changes, regressions, and neutral changes.
  - `to_dict()`: Converts the report into a dictionary for further processing or logging.

#### `diff_snapshots` Function
- **Purpose**: Compares two snapshots and produces a `DeltaReport`.
- **Logic**:
  - Compares the "services", "git", "postgres", and "integrity" sections of the snapshots.
  - Detects new services, changes in service states, missing services, Git commit changes, PostgreSQL table and row count changes, and integrity issues (missing files, unhealthy services).
  - Adds detected changes to the `DeltaReport`.

#### `print_delta_report` Function
- **Purpose**: Formats and prints the `DeltaReport` to the terminal.
- **Logic**:
  - Prints a header with optional labels for pre and post snapshots.
  - Iterates through the `DeltaEntry` objects in the report and prints them with appropriate icons and messages.
  - Prints a summary line and a warning if any regressions are detected.

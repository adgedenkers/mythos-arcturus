### Detailed Breakdown of Nodes

1. **Node 1: Context**
   - Captures the setting, circumstances, and intent behind the conversation.
   - JSON Structure:
     ```json
     {
       "node_1_context": {
         "setting": "string",
         "prompt_intent": "string",
         "initial_state": "string"
       }
     }
     ```

2. **Node 2: Entities**
   - Lists all entities (people, places, systems, concepts, projects, tools, spiritual entities) mentioned in the conversation.
   - JSON Structure:
     ```json
     {
       "node_2_entities": [
         {"name": "string", "type": "person|place|system|concept|entity|tool", "context": "string"}
       ]
     }
     ```

3. **Node 3: Actions**
   - Records concrete actions and decisions taken during the conversation.
   - JSON Structure:
     ```json
     {
       "node_3_actions": [
         {"action": "string", "actor": "string", "completed": true|false}
       ]
     }
     ```

4. **Node 4: States**
   - Captures emotional, energetic, or mental states mentioned or evident in the exchange.
   - JSON Structure:
     ```json
     {
       "node_4_states": [
         {"state": "string", "who": "string", "when": "start|during|end"}
       ]
     }
     ```

5. **Node 5: Relationships**
   - Lists relationships between entities established, clarified, or referenced.
   - JSON Structure:
     ```json
     {
       "node_5_relationships": [
         {"from": "string", "to": "string", "relationship": "string"}
       ]
     }
     ```

6. **Node 6: Timestamps**
   - Captures any dates, times, cycles, or temporal references.
   - JSON Structure:
     ```json
     {
       "node_6_timestamps": [
         {"reference": "string", "type": "absolute|relative|cyclical", "value": "string"}
       ]
     }
     ```

7. **Node 7: Artifacts**
   - Lists documents, code, files, images, or outputs created, modified, or referenced.
   - JSON Structure:
     ```json
     {
       "node_7_artifacts": [
         {"name": "string", "type": "string", "action": "created|modified|referenced", "path": "string|null"}
       ]
     }
     ```

8. **Node 8: Open Threads**
   - Captures questions left unanswered, tasks incomplete, or things marked for return.
   - JSON Structure:
     ```json
     {
       "node_8_open_threads": [
         {"thread": "string", "type": "question|task|exploration", "priority": "high|medium|low"}
       ]
     }
     ```

9. **Node 9: Declarations**
   - Lists statements of identity, purpose, truth, or principle claimed or affirmed.
   - JSON Structure:
     ```json
     {
       "node_9_declarations": [
         {"declaration": "string", "speaker": "string", "domain": "identity|purpose|truth|principle"}
       ]
     }
     ```

This markdown file serves as a blueprint for the extraction process, ensuring that all relevant information is captured in a structured and consistent manner.

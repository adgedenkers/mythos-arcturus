### File: `iris/introspection/report.py`

#### Purpose
This file contains functions to generate and format health reports based on introspection runs. The `generate_report` function creates a structured dictionary report, while the `format_report_text` function formats this report into a human-readable text format suitable for CLI or Telegram output.

#### Architecture
The file consists of two main functions:
1. `generate_report`: This function takes various parameters and constructs a detailed health report dictionary.
2. `format_report_text`: This function takes the report dictionary and formats it into a human-readable text format.

1. **`generate_report`**:

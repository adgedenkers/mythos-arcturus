## Summary

This is the initialization file for AutoDoc2 version 2.0.0-phase1, a codebase documentation tool that crawls directories, uses tree-sitter to parse code files, and outputs structural data to Neo4j along with markdown summaries. It currently supports Python in its first phase, with planned expansion to JavaScript/TypeScript and eventually SQL, PHP, Go, Bash, and YAML. The file establishes the package structure and versioning for this multi-phase documentation engine.
